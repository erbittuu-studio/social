# Events and festivals

The dates are not written here. They are in `../faststore/data/apps/<store id>/events.json` (the in-app events) and must be checked against a proper calendar before a post is `ready`. The pictures of each event are in `../faststore/data/media/pages/<store id>/<event>/` (App Store screens) and, for the festival day itself, in `images/greetings/`.

## How an event is posted

- A reminder before the day, a post on the day, and one after while the event page is still open.
- Event days use the event's own pictures and link to the matching App Store custom page, not the general pictures.
- A 90-day plan from early November runs to the start of February, so it reaches every event in the table, including the January ones.

## Missing

- App Store event pictures for Makar Sankranti and New Year. The greeting pictures cover the day itself.
- Pictures for Hindu observances without an app event, for example monthly Ekadashi and Purnima.
